# Janani-Net

Federated Learning for maternal health risk prediction (Low / Mid / High)
from 6 vitals — Age, Systolic BP, Diastolic BP, Blood Glucose, Body Temp,
Heart Rate.

Instead of centralizing patient records from multiple hospitals into one
training set (a privacy/legal problem, and one that biases the model toward
whichever hospital's patient population dominates the data), each simulated
hospital trains locally on its own data and only shares model weights. This
also lets us handle non-IID data across hospitals — a model trained mostly
on urban hospital records tends to perform badly on rural clinic patients,
since the underlying distributions differ.

Built with [Flower](https://flower.ai/) for FL orchestration (FedProx
strategy) and PyTorch for the model, trained/simulated locally on the
[UCI Maternal Health Risk dataset](https://archive.ics.uci.edu/dataset/863/maternal+health+risk)
(1014 records).
